# Site de Vagas · OptimusTech

Página de estudo do desafio 7 Days of Code, desenvolvida com HTML e CSS. O layout apresenta uma empresa fictícia, métricas ilustrativas, vagas por área e um depoimento de exemplo.

## Executar

Abra `index.html` no navegador ou execute `python -m http.server 8000` na raiz e acesse http://localhost:8000. Não há dependências, backend nem etapa de build.

## Interface

- Navegação por âncoras para apresentação, resultados e vagas
- Cards e conteúdo ajustados para telas pequenas
- Navegação semântica, foco visível e link para pular ao conteúdo
- Cadastro explicitamente desativado, sem coleta de e-mail

## Limitações

Vagas, salários, métricas e depoimento fazem parte do exercício visual; não são anúncios reais. Entrar, cadastrar e acompanhar oportunidades são elementos demonstrativos, sem autenticação ou envio de dados.

## Verificação manual

Confira as larguras de 320, 768 e 1440 px, zoom de 200%, navegação por Tab e links internos. A página não deve exigir rolagem horizontal. Não há suíte de testes automatizada configurada.

## Estrutura

`index.html`: conteúdo e estrutura · `style.css`: estilos · `assets/`: imagens do exercício.
